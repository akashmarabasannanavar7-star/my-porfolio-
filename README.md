# Akash's Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Before you deploy
1. Add your photo as `assets/photo.jpg` (portrait, roughly 4:5). Until then the site shows your initials.
2. In `index.html`, search for `your.email@example.com`, `your-username` and replace them with your real email, GitHub and LinkedIn.

## Preview locally
Open `index.html` in a browser.

## Deploy on Vercel
**Option A: GitHub (recommended)**
1. Push this folder to a GitHub repo.
2. On vercel.com choose Add New, then Project, and import the repo.
3. Framework preset: Other. Leave build and output settings empty. Deploy.

**Option B: Vercel CLI**
```
npm i -g vercel
cd akash-portfolio
vercel --prod
```
